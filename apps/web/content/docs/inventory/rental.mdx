# Event hire (rental)

Hire is **not a sale**. A rental SKU does not post COGS and does not permanently leave the warehouse on the invoice. Stock moves only on dispatch, return, wash, repair, or write-off.

Enable the **rental** module (Control Room), then **Company → Rental**.

## Cycle

1. Quote / order / invoice with hire from–to (and venue / pax).
2. Availability blocks overlapping Saturdays (or warns / manager override — tenant setting).
3. Invoice timing: on confirm, on dispatch, after return, or manual.
4. Collect deposit → liability **2400** (not sales).
5. **Dispatch** warehouse → On rent.
6. **Return:** good (warehouse or wash), dirty (wash), damaged (Repair), missing (write-off + optional **4450** charge).
7. **Mark ready** on Wash / Repair to send qty back to the warehouse.
8. Extend hire if the event runs long (re-checks overlap; optional extra **4400**).

## Accounts

| Code | Use |
|------|-----|
| 4400 | Hire income |
| 4450 | Damage / late / missing charges |
| 2400 | Customer deposits (liability) |
| 5150 | Fleet write-off |

Food and labour stay on the same invoice as physical / service lines.

## Kits

A hire SKU can list **kit components** (Product → Kit). Adding that SKU on a quote or invoice expands into the component lines (qty × kit qty) so chairs, tables, and tents reserve separately.

## Screens

- **Inventory → Dispatch / returns**
- **Inventory → Rental calendar**
- **Inventory → Stock levels** (On rent / Repair / Wash filters)
- Sales invoice → Event hire panel
- **Company → Rental**
